# Repository identity

Use [IzuSharp/Korda-Design](https://github.com/IzuSharp/Korda-Design) for current
clones, documentation links and GitHub requests. It was formerly named
`IzuSharp/NativeWeave-Design`. The companion repositories are
[Korda](https://github.com/IzuSharp/Korda) for product implementation and
[Plan](https://github.com/IzuSharp/Plan) for planning and progress.

Historical `NativeWeave` package/type names and source identifiers preserve their
recorded meaning. A repository rename does not rename persisted database objects,
change interfaces or grant current task authority. The historical API coverage
schema keeps its existing `$id` for format identity.

Keep canonical navigation current while identifying historical technical claims
with their actual source revision. Avoid duplicate snapshots and raw execution
receipts in the current tree. [The CI guide](../eng/ci/README.md) describes current
validation; no frozen worktree or full-history replay is required.
